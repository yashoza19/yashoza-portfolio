CSS has evolved dramatically in recent years. Features that once required JavaScript or complex workarounds are now native to the language. Let's explore some modern techniques that are changing how we build web interfaces.

## Container Queries

Container queries allow components to respond to their container's size rather than the viewport:

```css
.card-container {
  container-type: inline-size;
  container-name: card;
}

.card {
  display: grid;
  grid-template-columns: 1fr;
}

@container card (min-width: 400px) {
  .card {
    grid-template-columns: 200px 1fr;
  }
}
```

<Callout type="tip" title="Game Changer">
Container queries enable truly modular components that adapt to their context, not just the viewport size. This is revolutionary for component-based architectures.
</Callout>

## Cascade Layers

Cascade layers give you control over specificity:

```css
@layer reset, base, components, utilities;

@layer reset {
  * {
    margin: 0;
    padding: 0;
  }
}

@layer base {
  body {
    font-family: system-ui;
    line-height: 1.5;
  }
}

@layer components {
  .button {
    padding: 0.5rem 1rem;
    border-radius: 0.25rem;
  }
}

@layer utilities {
  .text-center {
    text-align: center;
  }
}
```

The layer order determines specificity, making your CSS more predictable and maintainable.

## :has() Selector

The `:has()` pseudo-class (parent selector) opens up new possibilities:

```css
/* Style a card differently if it contains an image */
.card:has(img) {
  display: grid;
  grid-template-columns: 200px 1fr;
}

/* Style a form with errors */
form:has(input:invalid) {
  border: 2px solid red;
}

/* Navigation with active submenu */
nav:has(.submenu:hover) {
  background: rgba(0, 0, 0, 0.1);
}
```

## Subgrid

Subgrid allows nested grids to participate in the parent grid:

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
}

.card {
  display: grid;
  grid-row: span 2;
  grid-template-rows: subgrid; /* Align with parent grid rows */
}
```

This solves the common problem of aligning nested grid items with the parent grid.

## Modern Custom Properties

CSS custom properties (variables) now support more complex patterns:

```css
:root {
  --primary-hsl: 220 90% 56%;
  --spacing-unit: 0.5rem;
}

.element {
  /* Use hsl() with custom properties */
  background: hsl(var(--primary-hsl));

  /* Modify opacity */
  border: 1px solid hsl(var(--primary-hsl) / 0.5);

  /* Computed values */
  padding: calc(var(--spacing-unit) * 2);
  margin: calc(var(--spacing-unit) * 4);
}

/* Responsive spacing system */
@media (min-width: 768px) {
  :root {
    --spacing-unit: 0.75rem;
  }
}
```

## Color Functions

Modern color functions provide powerful color manipulation:

```css
.element {
  --base-color: oklch(60% 0.15 280);

  background: var(--base-color);

  /* Lighter variant */
  border-top: 1px solid oklch(from var(--base-color) calc(l + 0.1) c h);

  /* Darker variant */
  border-bottom: 1px solid oklch(from var(--base-color) calc(l - 0.1) c h);

  /* Adjust saturation */
  box-shadow: 0 4px 6px oklch(from var(--base-color) l calc(c * 0.5) h / 0.3);
}
```

<Callout type="info" title="Color Spaces">
OKLCH provides perceptually uniform colors, making it easier to create accessible color palettes programmatically.
</Callout>

## Scroll-Driven Animations

Native scroll-triggered animations without JavaScript:

```css
@keyframes fade-in {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.section {
  animation: fade-in linear;
  animation-timeline: view();
  animation-range: entry 0% entry 100%;
}
```

## View Transitions API

Smooth transitions between page states:

```css
::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 0.3s;
}

::view-transition-old(header) {
  animation: slide-out 0.3s ease-out;
}

::view-transition-new(header) {
  animation: slide-in 0.3s ease-in;
}
```

Combined with JavaScript:

```javascript
document.startViewTransition(() => {
  // Update the DOM
  updateUI();
});
```

## Best Practices

1. **Progressive Enhancement** - Use modern features with fallbacks
2. **Feature Detection** - Use `@supports` for critical features
3. **Performance** - Modern CSS is fast, but measure impact
4. **Accessibility** - Test with screen readers and keyboard navigation
5. **Browser Support** - Check [caniuse.com](https://caniuse.com) for compatibility

## Conclusion

Modern CSS gives us unprecedented control over layout, styling, and interactions. These features reduce our dependence on JavaScript, improve performance, and make our code more maintainable.

Start experimenting with these techniques in your projects. The future of CSS is already here.
