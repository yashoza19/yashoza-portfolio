# Yash Oza Portfolio

Personal portfolio website showcasing my work as a Senior DevOps & Software Engineer.

## 🌐 Live Site

Visit the live portfolio at: [yashoza-portfolio.vercel.app](https://yashoza-portfolio.vercel.app)

## 🚀 About

I'm a Senior DevOps Engineer with 5+ years of experience building and operating scalable Kubernetes-based infrastructure, CI/CD systems, and cloud-native platforms on AWS. Currently at Red Hat, working on AI application deployment and developer platform engineering.

## ✨ Features

- **Modern Design**: Dark-themed, cinematic portfolio with smooth animations
- **Blog System**: Technical writing on DevOps, Kubernetes, and infrastructure
- **Project Showcase**: Featured projects with live demos and source code
- **Contact Form**: Web3Forms integration for direct communication
- **Analytics**: Vercel Analytics for visitor tracking and insights
- **Performance**: Optimized for speed with Core Web Vitals monitoring

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animation**: GSAP + Framer Motion
- **3D Graphics**: Three.js via React Three Fiber
- **Blog**: MDX with syntax highlighting
- **Deployment**: Vercel with automated CI/CD

## 📦 Key Dependencies

- `next` - React framework
- `gsap` - Animation library
- `three` - 3D graphics
- `@react-three/fiber` & `@react-three/drei` - React Three.js ecosystem
- `framer-motion` - Page transitions
- `lenis` - Smooth scrolling
- `next-mdx-remote` - MDX blog system
- `@vercel/analytics` - Privacy-friendly analytics

## 🏃 Local Development

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Preview production build
pnpm start
```

Visit [http://localhost:3000](http://localhost:3000) to view the site locally.

## 📝 Environment Variables

Create a `.env.local` file with:

```env
NEXT_PUBLIC_WEB3FORMS_KEY=your_web3forms_access_key
```

Get your Web3Forms key at [web3forms.com](https://web3forms.com).

## 🚀 Deployment

The site automatically deploys to Vercel when changes are pushed to the `main` branch via GitHub Actions.

For deployment setup instructions, see [DEPLOYMENT.md](./DEPLOYMENT.md).
